# Kubelog Common

This package contains common Backstage Kubelog declartions for use by both frontend plugin and backend plugin. Versions for all three packages must be the same.

## Version compatibility
Following table shows version compatibility between Kubelog and Kwirth Core.

| Plugin Kwirth version | Kwirth version |
|-|-|
|0.11.7|0.4.131|
|0.11.6|0.4.20|
|0.11.1|0.3.160|
|0.10.1|0.2.213|
|0.9.5|0.2.8|
